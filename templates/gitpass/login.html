Zero Server Retention

  • AES-256-GCM Encryption: Derived using PBKDF2 (120,000 rounds) directly from your master password.
  • GitHub as Storage: All ciphertexts live in your private repository file.
  • Zero Database Storage: We do not run or store user databases on Render.
  • Complete User Sovereignty: You can delete the repository anytime directly on GitHub.

Quick 3-Step Setup

  1. Create a repository (e.g. my-passwords) on GitHub.
  2. Generate a GitHub PAT with repo scope.
  3. Enter your credentials and master password to unlock!
