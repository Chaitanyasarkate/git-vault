Zero Server Retention

  • Encrypted with AES-256-GCM using key derived via PBKDF2 (120,000 iterations).
  • Stored in your GitHub Repository. Only encrypted ciphertext lives in your repo.
  • Zero database storage on Render. We do not store your passwords on any server disk or database.
  • Complete User Sovereignty: You can delete the repository anytime directly from GitHub or within Git-Pass.

3-Step Quick Start

  1. Create a repository (e.g. my-passwords) on GitHub.
  2. Generate a GitHub Personal Access Token with repo scope.
  3. Enter your details and Master Password above to open your vault!
