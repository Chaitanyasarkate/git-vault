Git-Pass Setup Instructions

Follow these straightforward steps to set up your private GitHub repository for password storage.

1

Create a GitHub Account

If you don't already have one, create a free GitHub account at github.com. You will need this account to store your encrypted password data securely in your own repository.

2

Generate a Personal Access Token (PAT)

Generate a Personal Access Token to allow Git-Pass to access and update your encrypted file in your repository:

GitHub Personal Access Token Generator ↗

Important scopes to select:

  • repo: Gives full control of private repositories to read & write the encrypted file.
  • delete_repo (optional): Only needed if you want the ability to delete the entire repo from Git-Pass settings.

Copy and save your token securely immediately — GitHub will never show it to you again!

3

Create a Dedicated GitHub Repository

Create a new repository on GitHub (e.g., gitpass-vault or my-passwords).

We recommend setting the repository to Private for maximum confidentiality, though your password data will be strongly encrypted with AES-256-GCM either way.

4

Add a File to Initialize the Repository

Add any file to your repository to initialize it. For example:

📄 passwords.txt
📄 data.json
📄 vault.dat

The file can be completely empty initially. Git-Pass will automatically format and store your encrypted ciphertext in this file.

5

Connect and Unlock Your Vault

Return to the login screen and enter your:

  • GitHub Username: Your GitHub account handle
  • Personal Access Token: The token created in step 2
  • Repository Name: The repository created in step 3
  • Filename: The filename selected in step 4 (e.g. passwords.txt)
  • Master Password: Your chosen strong master passphrase
CRITICAL: Your master password is never stored anywhere on our backend servers. If you forget your master password, your encrypted data cannot be decrypted or recovered!
