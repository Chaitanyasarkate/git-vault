Git-Pass Setup Instructions

Follow these 5 straightforward steps to configure your private GitHub repository for zero-knowledge password storage.

1

Create a GitHub Account

If you don't already have one, create a free account at github.com ↗. Your account is where your encrypted password data will live securely under your sole ownership.

2

Generate a Personal Access Token (PAT)

Generate a Personal Access Token on GitHub to authorize Git-Pass to read and write your encrypted file:

Open GitHub Token Generator ↗

Important scopes to select:

  • repo: Gives full control of repositories to read and write your encrypted file.
  • delete_repo (optional): Only needed if you want the option to delete the entire repo from Git-Pass settings.

Copy and save your token immediately — GitHub will only show it to you once!

3

Create a Dedicated GitHub Repository

Create a new repository on GitHub (e.g. my-passwords-vault or gitpass-data).

We recommend setting the repository visibility to Private for maximum confidentiality, though your password data is strongly encrypted with AES-256-GCM either way.

4

Add a File to Initialize the Repository

Add any text file to your repository to initialize it. For example:

📄 passwords.txt
📄 data.json
📄 vault.dat

The file can be completely empty initially. Git-Pass will automatically format and store your encrypted ciphertext in this file upon first connect.

5

Connect and Unlock Your Vault

Return to the login screen and enter your:

  • GitHub Username: Your GitHub account handle
  • Personal Access Token: The token created in step 2
  • Repository Name: The repository created in step 3
  • Filename: The filename chosen in step 4 (e.g. passwords.txt)
  • Master Password: Your chosen strong master passphrase
CRITICAL: Your master password is never stored anywhere on our backend servers. If you forget your master password, your encrypted data cannot be decrypted or recovered!
